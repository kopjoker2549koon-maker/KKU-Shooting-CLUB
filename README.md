# 🎯 KKU SHOOTING CLUB (ระบบบริหารจัดการชมรมกีฬายิงปืน มหาวิทยาลัยขอนแก่น)

ระบบบริหารจัดการชมรมกีฬายิงปืน มหาวิทยาลัยขอนแก่น ฉบับพร้อมเผยแพร่ใช้งานจริง (Production Release) รองรับทั้งการเข้าใช้งานผ่านคอมพิวเตอร์และอุปกรณ์มือถือ (PWA Mobile Ready) พร้อมระบบบัตรสมาชิกดิจิทัลและสแกนเนอร์หน้าสนามยิงปืน

---

## 🌟 จุดเด่นและฟังก์ชันหลักของระบบ (Core Features)

1. **บัตรสมาชิกดิจิทัล (Digital Membership Card) & Range Scanner**:
   - บัตรสมาชิกดีไซน์พรีเมียม Obsidian Blue & Gold พร้อม QR Code ประจำตัวสมาชิก
   - เจ้าหน้าที่สนาม (Operator) สามารถสแกนบัตรสมาชิกด้วยกล้องมือถือ/แท็บเล็ต หรือพิมพ์ค้นหาเพื่อตัดเบิกจ่ายกระสุนและเป้าซ้อมยิงได้แบบเรียลไทม์
   - รองรับการติดตั้งแบบ PWA (Add to Home Screen) บน iOS และ Android

2. **ระบบความปลอดภัยและการยืนยันตัวตน (Security & Compliance)**:
   - รหัสผ่านเข้ารหัสด้วยมาตรฐาน **Scrypt / PBKDF2 Cryptographic Hash** 100%
   - บังคับใช้อีเมลมหาวิทยาลัยขอนแก่น **`@kkumail.com`** เท่านั้นในการสมัครสมาชิกและการกู้คืนรหัสผ่านด้วยรหัส OTP
   - กลไกป้องกันการตัดยอดกระสุนเกินคลัง (Inventory Guardrails): แจ้งเตือนข้อผิดพลาดทันทีหากสั่งลดเกินจำนวนที่มีอยู่จริงในคลัง
   - รองรับกฎความปลอดภัย 4 ประการแห่งการใช้อาวุธปืน (Gun Safety Rules Checkbox) ก่อนส่งใบสมัคร

3. **ระบบครอบตัดรูปภาพแบบออฟไลน์ (Interactive Image Cropper)**:
   - ติดตั้ง Cropper.js แบบ Local Assets ทำงานได้แม้อยู่ในเครือข่ายอินทราเน็ตสนามยิงปืนที่ไม่มีอินเทอร์เน็ตภายนอก
   - ครอปรูปโปรไฟล์สัดส่วน 1:1 และสลิปการโอนเงินแบบ Free-form ได้อย่างราบรื่น

4. **การกรอกฟอร์มแบบ Inline & No-Reload**:
   - เมื่อกรอกข้อมูลผิดพลาด ระบบจะไม่ล้างข้อมูลในฟอร์ม ผู้ใช้สามารถแก้ไขเฉพาะจุดที่มีปัญหาได้ทันทีโดยไม่ต้องเริ่มต้นใหม่ทั้งหมด

5. **แดชบอร์ดผู้บริหาร (God Executive Dashboard)**:
   - สรุปตัวเลขสถิติสมาชิก ยอดสต็อกกระสุน และยอดคำสั่งซื้อ
   - อนุมัติ/ปฏิเสธคำขอเปิดบัญชีกรรมการสนามแบบ Real-time
   - ส่งออกรายชื่อสมาชิกชมรมเป็นไฟล์ **Excel / CSV (พร้อม UTF-8 BOM)** เพื่อส่งรายงานให้กองพัฒนานักศึกษาและศิษย์เก่า (กพศ. มข.)
   - ดาวน์โหลดไฟล์สำรองฐานข้อมูลทั้งหมด (`.db`) แบบออนไลน์ได้ทันที

## 🚀 วิธีการเปิดใช้งานระบบ (Production Startup)

### วิธีที่ 1: ดับเบิลคลิกเปิดใช้งานบน Windows (One-Click)
ดับเบิลคลิกที่ไฟล์ **`start_server.bat`** ในโฟลเดอร์โปรเจกต์ ระบบจะเริ่มทำงานผ่าน Production WSGI Server (Waitress) ทันที

### วิธีที่ 2: รันผ่าน Command Line
```powershell
# 1. ติดตั้งไลบรารีที่จำเป็น
py -m pip install -r requirements.txt

# 2. เริ่มต้นเซิร์ฟเวอร์
py run.py
```

เมื่อเปิดใช้งาน หน้าต่างคอนโซลจะแสดงลิงก์เชื่อมต่อ:
- **เข้าใช้งานในเครื่องคอมพิวเตอร์**: `http://localhost:5000`
- **เข้าใช้งานผ่านมือถือ/แท็บเล็ตในวง WiFi เดียวกัน**: `http://<Local_IP>:5000` (เช่น `http://10.10.1.32:5000`)

## 🛠️ โครงสร้างเทคโนโลยี (Tech Stack)

- **Backend**: Python 3.14 + Flask 3.1
- **WSGI Production Server**: Waitress 3.0.2 (Multi-threaded 8 Workers)
- **Database**: SQLite 3 (เปิดใช้งานโหมด **WAL: Write-Ahead Logging** เพื่อ Concurrency สูงสุด ป้องกันปัญหาฐานข้อมูลล็อก)
- **Frontend**: HTML5, Vanilla JavaScript, CSS3 Obsidian & Amber Theme, Bootstrap 5, Bootstrap Icons
- **Offline Libraries**:
  - `cropper.min.js` & `cropper.min.css` (ครอบตัดรูปภาพ)
  - `qrcode.min.js` (สร้าง QR Code บัตรสมาชิก)
  - `html5-qrcode.min.js` (สแกนเนอร์กล้องอ่านบัตรหน้าสนาม)
  - `sw.js` & `manifest.json` (Service Worker แคชไฟล์ออฟไลน์และรองรับ PWA)
